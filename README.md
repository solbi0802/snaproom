# Snaproom

중고 거래나 SNS 공유용 사진을 브라우저에서 배치하고, 가리고, 꾸민 뒤 한 장의 PNG로 저장하는 사진 작업대입니다. 선택한 사진은 기기에서 처리되며, 새로고침하면 현재 편집이 사라집니다.

[Snaproom 열기](https://snaproom-weld.vercel.app/)

## 사용 방법

1. JPG·PNG·WebP 사진을 1~4장 선택하거나 끌어 놓습니다. 한 장당 최대 20MB이며, 샘플 일러스트로도 체험할 수 있습니다.
2. 사진 카드를 끌어 순서를 바꾸고 **사진 배치 시작**을 누릅니다. 기본 배치와 첫 사진 강조 배치를 선택할 수 있습니다. 첫 사진 강조는 3~4장일 때 제공됩니다.
3. 가릴 부분에 모자이크를 적용하고, 스티커와 배경색·여백을 조절합니다. 모자이크 영역은 드래그하거나 숫자로 지정할 수 있습니다.
4. **저장 미리보기**에서 결과를 확인하고 1000×1000 PNG를 다운로드합니다.

키보드로 순서를 바꾸려면 사진 카드에 포커스를 두고 `Space` → 방향키 → `Space`를 누릅니다. 스티커는 방향키로 이동하고, 모서리에 포커스를 두면 방향키로 크기를 바꿀 수 있습니다. 배치·배경·여백·모자이크·스티커 편집은 **실행 취소** 또는 `Ctrl+Z`·`⌘+Z`로 되돌릴 수 있습니다.

## 구현

React·TypeScript·Vite와 CSS Modules를 사용합니다. 사진 순서 변경은 dnd-kit, 이미지 합성은 Canvas 2D로 구현했습니다.

- **이미지 처리** — 파일 형식·크기·사진 수를 검사하고, 브라우저에서 읽을 수 있는 사진을 목록에 추가합니다. 업로드 검증 단계에서 디코딩한 사진은 편집 화면에서 재사용합니다.
- **좌표와 렌더링** — 모자이크는 사진 ID와 원본 기준 정규화 좌표로 저장됩니다. 순서나 배치가 바뀌어도 해당 사진의 같은 영역에 적용됩니다. 스티커는 문서 좌표에 배치합니다.
- **드래그와 이력** — 스티커 드래그 중에는 화면 프레임에 맞춰 미리보기를 갱신하고, 드래그가 끝날 때 편집 이력을 한 번 기록합니다.
- **PNG 내보내기** — 미리보기와 저장에 같은 합성 규칙을 사용합니다. 선택 테두리와 크기 조절점은 편집 화면에만 표시합니다.

| 경로 | 역할 |
| --- | --- |
| `src/app/` | 화면 전환, 사진 자산, 편집 문서 상태 |
| `src/features/upload/` | 파일 제한 검사, 사진 카드 순서 변경 |
| `src/features/editor/` | 편집 도구, 편집 이력, 입력 처리 |
| `src/rendering/` | 레이아웃, 좌표 변환, Canvas 합성 |
| `src/shared/` | 공통 컨트롤과 디자인 토큰 |
| `e2e/` | 데스크톱·모바일 Chromium 사용자 흐름 검증 |

## 로컬 실행과 검증

Node.js 22.13 이상(22.x) 또는 24 이상을 사용합니다.

```sh
npm ci
npm run dev
```

```sh
npm run check
npx playwright install chromium
npm run test:e2e
```

`npm run check`는 타입·린트·UI 규칙·단위 테스트·프로덕션 빌드를 실행합니다. Playwright는 파일 제한, 사진 순서 변경, 모바일 터치와 키보드, 여러 편집이 합쳐진 PNG의 픽셀, 저장 실패 후 재시도를 확인합니다. GitHub Actions에서도 같은 검사를 실행합니다.

## 배포

Vercel에서 Vite 프로젝트로 빌드합니다. 빌드 명령은 `npm run build`, 출력 폴더는 `dist`입니다. 설정은 [vercel.json](vercel.json)에 있습니다.
