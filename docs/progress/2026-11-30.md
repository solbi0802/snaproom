# 11월 30일 계획 — 사진 배치와 PNG 저장

- 11월 27일에 미리 구현했다. 사진 1~4장을 기본 배치로 합치고, 3~4장에서는 첫 사진 강조 배치도 사용할 수 있다.
- 미리보기와 PNG 저장이 같은 배치 계산과 중앙 자르기 규칙을 사용한다. 저장 전 미리보기에서 배치 화면으로 돌아가도 선택한 배치가 유지된다.
- 전체 검사와 빌드, 단위 테스트 7개, 데스크톱·모바일 Chromium 테스트 16개가 통과했다. 브라우저에서 내려받은 파일의 PNG 형식과 1000×1000 크기도 확인했다.
- 다음 작업은 모자이크 영역 선택과 원본 이미지 좌표 변환이다.
